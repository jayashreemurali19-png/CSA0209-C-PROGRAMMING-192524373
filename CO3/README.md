## Tariff assumptions
- Fixed charge: Rs 5.00 (500 paise), chosen because the assignment does not specify a fixed-charge amount.
- First 100 units: free energy charge.
- Units 101–200: Rs 2.25 per unit.
- Units above 200: Rs 4.50 per unit.
- Meter rollover: 16-bit readings; when current < previous, units are calculated as `(65536 - previous) + current`.
- Money is represented in integer paise to avoid binary floating-point errors.

- Task 3: separate examples demonstrate integer division, floating-point approximation and cast truncation.
