# Progressive GitHub commit plan

Use the actual repository after creating it; these commands demonstrate separate commits.

```sh
git init
git branch -M main
git add Task01
git commit -m "Complete Task 1: header guards and debug mode"
git add Task02
git commit -m "Complete Task 2: validated input and billing output"
git add Task03
git commit -m "Complete Task 3: type conversion and precision analysis"
git add Task04
git commit -m "Complete Task 4: GCC compilation stages"
git add README.md report
git commit -m "Add assignment report and README"
git remote add origin <your-repository-url>
git push -u origin main
```

Replace `<your-repository-url>` with the URL of the repository you actually created. Do not claim commits exist until you run these commands.
